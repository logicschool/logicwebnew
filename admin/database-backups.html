Checking your session…

What is included?

Website content, settings, results, testimonials, courses, leads, media records and admin accounts. Active login sessions are excluded.

Images, PDFs, website files and .env are not included. Back up uploads and server files separately. Keep backups private: they contain contact details and account hashes. Restore only trusted backups from this CMS version.

Create a backup

A copy is saved on the server and can be downloaded below. Maximum size: 25 MB.

Restore a backup

This replaces the current database records, including admin accounts. Run during a maintenance window. A recovery copy is saved before replacement; any database error rolls back the restore. All users must sign in again with accounts from the backup.

If you run multiple CMS instances, stop the other instances before restoring and restart them afterward.

Saved database backups

Download a copy to another device. Recovery copies are kept until removed by your server administrator.
